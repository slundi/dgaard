dgaard Settings

Configure the connection to your dgaard-rest API

The base URL of your running dgaard-rest instance. Defaults to http://127.0.0.1:8080.

Non-localhost URLs require an additional host permission. Add the origin to host_permissions in manifest.json and reload the extension.

Required when dgaard-rest is started with --auth-token.

When set, the popup shows an "Open Monitor →" link to your dgaard-monitor instance.
